                Saved networks

                  Save your phone's hotspot and the box joins it whenever your home Wi-Fi isn't around, so printing from packs.ink works anywhere. The box stays where it is now. Turn the hotspot on before you plug the box in: it looks for it when it starts, then only every few minutes. On Android it's under Settings › Hotspot; if the box can't join, set the hotspot's security to WPA2.
